# 03：检查点、长期记忆与时间旅行

## 1. Checkpointer 与 Store 是两类存储

| 能力 | Checkpointer | Store |
| --- | --- | --- |
| 主要键 | `thread_id` | 自定义 namespace + key |
| 保存内容 | 每一步图状态快照 | 应用主动写入的任意业务记忆 |
| 典型用途 | 暂停恢复、对话上下文、历史、时间旅行 | 跨线程用户偏好、知识或档案 |
| 本项目实现 | `MemorySaver` | `InMemoryStore` |

不要用 `thread_id` 代替用户身份。同一用户可以创建很多 thread；同一个 thread 也不应
被不同用户共享。

## 2. 线程检查点

编译时传入 checkpointer：

```python
graph = builder.compile(checkpointer=MemorySaver())
```

调用时传入：

```python
config = {"configurable": {"thread_id": "conversation-1"}}
graph.invoke({"message": "第一条"}, config)
graph.invoke({"message": "第二条"}, config)
```

第二次调用会读取第一次的状态，`turn` 因而从 1 增长到 2。换成另一个
`thread_id`，计数从头开始。

## 3. 查看状态历史

```python
snapshots = list(graph.get_state_history(config))
```

每个 `StateSnapshot` 主要包含：

- `values`：当时的状态；
- `next`：接下来准备运行的节点；
- `config`：包含 checkpoint_id 的可复用配置；
- `metadata`：步骤、来源等元数据；
- `tasks`：待处理任务及 interrupt 信息。

历史通常按新到旧返回，业务代码不要未经确认就假设顺序。

## 4. 状态编辑与分支

```python
edited_config = graph.update_state(
    snapshot.config,
    {"turn": 40},
    as_node="record_turn",
)
result = graph.invoke({"message": "继续"}, edited_config)
```

`update_state` 不会修改旧快照，而是创建新检查点。使用返回的 config 继续执行，会形成
一条新的状态时间线。这正是调试、人工纠错和“如果当时输入不同会怎样”分析的基础。

## 5. interrupt 为什么必须依赖检查点

节点执行到 `interrupt()` 时需要保存：

- 当前状态；
- 暂停节点；
- interrupt 负载；
- 恢复后应继续的位置。

没有 checkpointer，跨调用恢复没有可靠依据。恢复时 thread_id 必须与暂停时相同。

## 6. 长期用户记忆

综合模式下节点可以通过 `get_store()` 获取编译时注入的 Store：

```python
namespace = ("users", user_id)
store.put(namespace, "profile", {"visits": 2})
item = store.get(namespace, "profile")
```

namespace 是元组，可以表示层级。例如：

- `("users", user_id)`：用户档案；
- `("courses", course_id, "notes")`：课程笔记；
- `("teams", team_id, "preferences")`：团队偏好。

## 7. 教学内存实现的限制

`MemorySaver` 和 `InMemoryStore` 在进程退出后数据消失。它们适合：

- 单元测试；
- 学习 API；
- 本地短期调试。

生产环境应使用与部署方式匹配的持久化 checkpointer/store，并执行初始化、连接池、
备份、数据保留和访问控制。参考工程包含 PostgreSQL checkpointer 依赖，但本教程不要求
启动外部数据库，因此没有把它设为默认依赖。

## 8. 建议练习

1. 用两个 thread_id 调用 `persistence`，比较 `turn`。
2. 用同一 user_id、两个 thread_id 调用 `memory`，确认 visits 累加。
3. 从历史中间快照继续，而不是从最新快照继续。
4. 给长期档案增加 `favorite_topics` 列表。
